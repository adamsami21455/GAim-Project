# GAim Project (Aim Game)
## Overview
This is a point and click game. You click on the targets to get a minmimum amount of score before the timer runs out. If you miss a target you lose a life. Once you lose 3 lives the game is over. The game gets progressively harder, there can be up to 4 bombs at a time.

## Technologies Used
1. HTML
2. CSS
3. JavaScript

## User Stories
- User should be able to type their name before starting the game
- User should be able to click on targets
- User should be able to click on bombs and lose lives
- User should be able to see their lives
- User should be able to look at the timer
- User should be able to see score
- User should be able to win or lose
- User should be able to play again
